# Changelog

## 0.1.0-alpha.1 — Unreleased

- Nonpackable experimental PDF starter: native-text/manual-region rasterized removal and optional NativePreserving whole intersecting text/image object removal with fresh page import and staged same-backend checks. Reject unsupported native page features, never fallback/overlay. Trusted development input only; no OCR/complete admission or supported PDF format registration.

- Optional independent Pdf.PdfPig managed structural inspector, neutral source-free observations and immutable read/traversal/decoded-byte limits. Classic tables, bounded direct Flate xref streams with restricted PNG predictors and guarded canonical Flate object streams with exact current-xref membership. Content payloads remain opaque; TIFF/hybrid/encrypted syntax remains refused. No secure admission or PDF redaction claim. Supplemental upstream notices/licenses are packaged.

- Optional provider-neutral OCR contracts, .NET Tesseract adapter and bounded SkiaSharp PNG/JPEG pixel redaction. Opt-in DOCX/XLSX picture handling rebuilds image payloads as metadata-free PNG and redacts alternative text; existing constructors retain image rejection. Native processing is in-process, not sandboxed; OCR accuracy and complete discovery are not guaranteed. See docs/formats/ocr.md.

- Restricted DOCX/XLSX Office package using centrally pinned MIT Open XML SDK 3.5.1: original-coordinate run edits, preserved unaffected formatting, properties/hidden-sheet recovery, bounded archive/XML/relationship validation, recursive supported package relationships and staged fresh output.
- Additive IEditAwareTextRedactor/RedactionEdit/EditRedactionResult contracts; Core executes detection/strategies once and optional DI shares the engine instance. Existing ITextRedactor/RedactionResult remain source-compatible.
- Restricted XLSX local-A1 arithmetic/function formulas preserved without cached values/calculation chains; full recalculation requested, not performed. Revisions, drawings/images, OLE, unknown/external/active/encrypted/signed content and other formulas fail closed. SDK/LibreOffice checks do not establish Microsoft Office or human visual fidelity.

- GitHub-facing README with original SVG logo/banner, clearly marked repository placeholders, real workflow badge endpoints, package/support tables and documentation navigation. No hosted status or deployment claim.
- New documentation index, getting-started and GitHub setup guides; expanded contributor guidance, bounded local link/SVG checks and a CI check step.
- Separate self-contained package README embedded as README.md in all eleven product packages, without GitHub-only artwork or placeholder links.
- CSV parsing/escaping now uses centrally pinned CsvHelper 33.1.0 under its Apache-2.0 option, with strict-profile regression coverage and an EOF quote-balance guard.
- Breaking alpha rename: NuntivusRedact root namespaces, project/assembly/package names and solution entry points; branded DI/HTTP APIs renamed consistently. No old packages were published. See docs/MIGRATION.md. Historical benchmark results retain their pre-rename provenance.

- Initial .NET 10 modular contracts, deterministic strict engine and immutable policies.
- Bounded regex/keyword/dictionary and heuristic personal-data detectors.
- Replacement, masking and HMAC-SHA256 pseudonymization strategies.
- Optional Microsoft DI, bounded UTF-8 TXT/CSV/JSON/XML profile and numeric source-free reports.
- Optional bounded ASP.NET raw-body integration with sanitized errors and a local OpenAPI sample; no production service claim.
- xUnit checks, executable synthetic samples, verification scripts and CI.
- PPTX/PDF, broader Office features and native-worker isolation remain unsupported. See the [backlog](docs/TASKS.md) for unfinished milestones. No NuGet publication performed.
- Experimental Pdf.Abstractions and Pdf.PdfiumCore libraries: replaceable owned sessions, UTF-16/display-space character geometry, bounded opaque rendering and fresh image-only PDF writing. Shared caller-owned runtime bounds native call/document admission. Native removal and secure PDF document processing remain unsupported; hidden-metadata retention is covered by characterization tests. See docs/formats/pdf.md. Isolated Windows x64 NuGet/native consumption is checked; Linux/isolation and native attribution review remain gates.
